Soporte de Playround

Estamos para ayudarte con el acceso y el funcionamiento de Playround.

Escribinos a playround1975@gmail.com. Intentaremos responder dentro de los próximos 3 días hábiles.

Cómo solicitar ayuda

Para que podamos ayudarte más rápido, incluí en tu mensaje:

  • Una descripción clara del problema.
  • Qué estabas intentando hacer cuando ocurrió.
  • El modelo de tu dispositivo y la versión del sistema operativo.
  • Una captura de pantalla, si resulta útil.

No envíes contraseñas, códigos de acceso ni otra información sensible.

Problemas de acceso

Si no podés iniciar sesión, verificá que tengas conexión a internet y que estés utilizando el mismo método de acceso con el que creaste tu cuenta. Si el problema continúa, escribinos indicando el correo asociado a tu cuenta.

Partidos, grupos, torneos y estadísticas

Si encontrás un resultado incorrecto, una diferencia en tus estadísticas o un problema dentro de un grupo o torneo, describí el caso y, cuando corresponda, incluí el nombre del torneo, grupo o rival involucrado.

Errores y funcionamiento

Si la aplicación se cierra, queda bloqueada o una función no responde, cerrala y volvé a abrirla. Si el problema persiste, contactanos con los datos indicados arriba para que podamos investigarlo.

Privacidad y eliminación de cuenta

Podés consultar nuestra Política de Privacidad y solicitar la eliminación de tu cuenta desde la aplicación o mediante la página de eliminación de cuenta y datos.
